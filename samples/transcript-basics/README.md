# A first transcript edit

This practice project contains a short recording, a waveform slate and an editable transcript. ScriptCut copies the recording into its writable sample folder when you open the project.

The script and slate were created for ScriptCut. The narration was synthesized locally with Piper using the Kathleen voice. The [model card](https://huggingface.co/rhasspy/piper-voices/blob/2f8dbe0/en/en_US/kathleen/low/MODEL_CARD) identifies the [Kathleen recordings](https://github.com/rhasspy/dataset-voice-kathleen) as CC0. ScriptCut distributes the rendered recording and timed transcript under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

> Well, every good edit starts with a decision. Keep the moment that tells the story. Then listen to the space between the words.
